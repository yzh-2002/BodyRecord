# 训练动作库与分组

根据用户提供的三张参考图整理。图中“各种”动作已拆成具体器械版本；臀桥与臀冲分别建条目。

共 70 个动作、9 个肌群分类。所有动作均有中文介绍、步骤、要点和可编辑难度。

支持三分化、四分化（手臂单练）、四分化（肩单练）。三分化提供图示组数；四分化仅提供分组。腹与臀都保留供按目标选择，不限制使用者性别。

## 难度与演示

容易 / 一般 / 困难沿用图示的参考分级；图中未分级的腹、臀和扩展动作采用补充等级。它表示默认技术学习标签，不是按重量或个人能力作出的训练评估，可在 App 内编辑。

内置 62 个经过实际画面核对的离线 GIF。对未找到精确素材的动作，不使用其他动作冒充；可导入自己的 GIF、WebP、JPG 或 PNG。

## 素材来源与用途

动图来源：[ExerciseDB V1 / AscendAPI 免费 API](https://oss.exercisedb.dev/docs)。使用者已确认仅个人使用、测试。当前素材版本为非商业用途并保留署名；中文说明由应用整理编写。

不使用第三方转存的全量素材包。每项下载来源和 SHA-256 校验值记录在 `exercise-media-manifest.json`。当前 App 不依赖网络播放演示；商业发布前需重新确认素材授权。

## 数据兼容

数据库从 v1 非破坏性升级为 v2。旧训练保留，新增动作引用、肌群与难度字段；历史记录保存当时的名称和标签，动作库编辑、隐藏或删除不会改写历史。

备份格式升级为 v2，同时读取旧 v1 格式。自定义动作、内置动作修改与隐藏状态、自选演示文件随备份保存；内置演示随安装包提供。
