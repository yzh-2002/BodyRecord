# 日历记录

“记录”页默认显示月历，周一为每周首日。左右箭头切换月份，“本月”回到当前月份。未来日期灰显，不创建未来的实际记录。小屏自动使用紧凑月历，当前 720×1280 模拟器可一屏显示整月与图例。

- 绿色点：训练日，下方展示训练部位简称；同日多个动作的同一部位只显示一次，部位较多时显示 `+`，点击当天查看完整部位和动作列表。
- 灰色点：明确标记的休息日。没有记录的日期保持空白，不据此判断休息。
- 橙色标记：当天含放纵餐。可以在当天标记，也可以在饮食表单中勾选具体餐次；任一来源成立就显示。
- “已记录”：当天有体重、饮食或备注，但尚未标记训练 / 休息。

点击日期打开当天详情，查看、编辑和删除体重、饮食照片、训练；也可补记记录或填写当天备注。训练部位使用每条训练保存时的快照，后续修改动作库不改变历史部位。

“编辑标记”可选择训练日、休息日或未标记，也可标记当天含放纵餐、填写备注。当天已有训练时自动显示训练日；如果先标休息后补记训练，会自动改成训练日，并保留放纵餐和备注。若要改成休息日，先修改或删除当天训练记录。

取消当天手动放纵餐标记后，若餐次仍标为放纵餐，日历继续显示；需进入对应餐次编辑取消。此规则使日历与餐次详情保持一致。

右上角搜索入口保留原有全部记录列表、关键词搜索和类型筛选。日历标记、单餐标签、食物库的新增 / 编辑 / 隐藏状态都随 ZIP 备份保存。数据库 v3→v4 非破坏升级，旧记录不自动推断为休息日或放纵餐。
